MON TRAVAIL

Salut ! Je suis Roberto. Passionné par l'architecture logicielle, je conçois des applications web complètes.

J'aime propulser des projets modernes et découplés en combinant la puissance de Symfony et la flexibilité de React / TypeScript. Pour moi, la sécurité est un aspect irréprochable et essentiel. C'est pourquoi j'intègre des concepts de validations strictes double niveau (front-end et back-end), authentification par tokens JWT et chiffrement des données.

Mon parcours professionnel m'a permis de comprendre la culture du livrable, la méthodologie de gestion de projet (JIRA, Git) et les deadlines serrées. Au-delà des lignes de code, j'aime travailler en équipe, avec toujours une forte autonomie, un sens de l'écoute et beaucoup d'enthousiasme au quotidien.

Tu cherches un collaborateur fiable, pointu techniquement et souriant pour renforcer ton équipe ?

MES PROJETS

Vite & Gourmand - Application E-Commerce de Commande Traiteur

API REST Symfony 7.4 & API Platform 3 | Front-end React & TypeScript

API REST performante avec Symfony et API Platform 3, consommée par un front-end moderne en React et TypeScript. L'application intègre une gestion des rôles, un tableau de statistiques dynamiques, un flux d'automatisation d'e-mails transactionnels et une architecture de données structurée.

Sécurité renforcée avec validation double niveau, authentification par tokens JWT, protection contre les failles XSS et injections via EventSubscriber.

EcoRide - Application Mobilité de Covoiturage

API REST Symfony 7.4 & API Platform 3 | Front-end React & TypeScript

Plateforme de covoiturage pensée pour gérer les trajets, les profils utilisateurs, les avis clients et les recherches dynamiques. L'interface consomme une API structurée et maintenable, avec une logique claire entre les espaces client et administrateur.

Implémentation d'un calcul de frais de livraison avec géocodage, sécurisation des échanges et traitement fiable des données métier.

Vite & Gourmand - Application Job Board de Recrutement

API REST Symfony 7.4 & API Platform 3 | Front-end React & TypeScript

Application de recrutement avec publication d'offres, gestion des candidatures et organisation des profils par rôle. Le projet met l'accent sur la lisibilité des parcours, la clarté des données et une intégration front-end fluide.

Architecture API-first, contrôles de sécurité côté client et serveur, et composants React pensés pour rester réutilisables dans une interface évolutive.
